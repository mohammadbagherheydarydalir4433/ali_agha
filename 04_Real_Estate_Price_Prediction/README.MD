# پیش‌بینی قیمت مسکن (Real Estate Price Prediction) با رگرسیون خطی ساده

این پروژه یک مدل رگرسیون خطی ساده (Simple Linear Regression) است که برای بررسی رابطه بین متراژ خانه (`metrazh`) و قیمت آن بر حسب تومان (`toman`) روی یک دیتاست املاک پیاده‌سازی شده است.

## ساختار پوشه
* **`j14.ipynb`**: نوت‌بوک جیومتریک شامل مراحل بارگذاری داده‌ها، آمار توصیفی، مصورسازی داده‌ها با نمودار پراکندگی (Scatter Plot)، آموزش مدل و ارزیابی خطا (MSE, MAE و R2-score).
* **`real_estate_dataset_1000.csv`**: دیتاست شامل اطلاعات املاک و مستغلات.

## ابزارها و کتابخانه‌ها
* **Python**
* **Pandas & NumPy**
* **Scikit-Learn** (برای مدل LinearRegression و معیارهای ارزیابی)
* **Matplotlib**
