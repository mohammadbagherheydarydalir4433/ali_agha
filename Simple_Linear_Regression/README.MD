# پیش‌بینی میزان انتشار دی‌اکسید کربن خودروها (CO2 Emissions Prediction) با رگرسیون خطی ساده

این پروژه شامل پیاده‌سازی مدل **رگرسیون خطی ساده (Simple Linear Regression)** با پایتون است تا رابطه خطی بین میزان مصرف ترکیبی سوخت (`FUELCONSUMPTION_COMB`) و میزان انتشار گاز دی‌اکسید کربن (`CO2EMISSIONS`) را مدل‌سازی و پیش‌بینی کند.

## ساختار پوشه
* **`j19.ipynb`** (یا نوت‌بوک پروژه): نوت‌بوک جیومتریک حاوی مراحل بارگذاری داده‌ها، رسم نمودارهای پراکندگی (`Scatter Plot`) به‌همراه خط رگرسیون برازش‌شده (`-r`)، تفکیک داده‌ها به مجموعه‌های آموزش و تست، و ارزیابی خطاهای مدل.
* **`FuelConsumption.csv`**: دیتاست استاندارد حاوی مشخصات مصرف سوخت و آلایندگی خودروها.

## مراحل و قابلیت‌های پروژه
1. **بارگذاری و بررسی داده‌ها:** خواندن فایل CSV و استخراج ستون‌های هدف و ویژگی‌ها[cite: 20].
2. **آموزش مدل رگرسیون خطی ساده:** تفکیک داده‌ها به بخش آموزش و آزمون (Train/Test) با نسبت 80 به 20 و محاسبه ضریب (`Coefficient`) و عرض از مبدأ (`Intercept`).
3. **مصورسازی مدل:** رسم نمودار پراکندگی داده‌های آموزشی و ترسیم خط رگرسیون بر روی آن‌ها.
4. **ارزیابی عملکرد مدل:** بررسی دقت و خطاهای پیش‌بینی با استفاده از معیارهای استاندارد:
   * میانگین خطای مطلق (`Mean Absolute Error - MAE`)
   * میانگین مربعات خطا (`Residual Sum of Squares / MSE`)
   * ضریب تعیین (`R2-score`)
