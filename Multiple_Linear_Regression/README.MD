# پیش‌بینی میزان انتشار دی‌اکسید کربن خودروها (CO2 Emissions Prediction) با رگرسیون خطی

این پروژه شامل تحلیل اکتشافی داده‌ها (EDA) و پیاده‌سازی مدل‌های **رگرسیون خطی ساده و چندگانه (Simple & Multiple Linear Regression)** با استفاده از پایتون است تا میزان انتشار گاز دی‌اکسید کربن خودروها (`CO2EMISSIONS`) را بر اساس مشخصات فنی خودرو (مانند حجم موتور، تعداد سیلندر و میزان مصرف سوخت) پیش‌بینی کند.

## ساختار پوشه
* **`j26.ipynb`** (یا نوت‌بوک پروژه): نوت‌بوک جیومتریک حاوی مراحل بارگذاری داده‌ها، رسم نمودارهای توزیع و پراکندگی (`Histogram` و `Scatter Plot`)، جداسازی داده‌ها به مجموعه‌های آموزش (Train) و تست (Test)، آموزش مدل رگرسیون خطی، و ارزیابی کیفیت مدل.
* **`FuelConsumption.csv`**: دیتاست استاندارد حاوی مشخصات مصرف سوخت و میزان انتشار CO2 خودروهای مختلف.

## مراحل و قابلیت‌های پروژه
1. **بارگذاری و بازبینی داده‌ها:** خواندن فایل CSV، بررسی اطلاعات آماری دیتاست با کمک `describe()` و نمایش ردیف‌های اولیه[cite: 18].
2. **تحلیل اکتشافی داده‌ها (EDA) و مصورسازی:**
   * رسم هیستوگرام برای ویژگی‌های عددی مختلف[cite: 18].
   * رسم نمودارهای پراکندگی (Scatter Plots) برای بررسی رابطه ویژگی‌هایی نظیر اندازه موتور (`ENGINESIZE`)، تعداد سیلندر (`CYLINDERS`) و مصرف ترکیبی سوخت (`FUELCONSUMPTION_COMB`) با میزان انتشار CO2.
3. **آموزش مدل رگرسیون خطی:** تفکیک داده‌ها به داده‌های آموزش و آزمون و آموزش مدل با استفاده از کتابخانه `scikit-learn`.
4. **ارزیابی عملکرد مدل:** بررسی خطاهای پیش‌بینی با استفاده از معیارهای کلیدی:
   * ضرایب رگرسیون (`Coefficients`)[cite: 18]
   * مجموع مربعات باقیمانده خطا (`Residual Sum of Squares - RSS`)
   * ضریب تعیین یا امتیاز واریانس (`Variance Score / R^2`)

## ابزارها و کتابخانه‌های مورد استفاده
