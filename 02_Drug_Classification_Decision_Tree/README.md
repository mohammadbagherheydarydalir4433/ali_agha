# دسته‌بندی داروها (Drug Classification) با درخت تصمیم

این پروژه یک مدل یادگیری ماشین با استفاده از الگوریتم **درخت تصمیم (Decision Tree)** است که برای پیش‌بینی و دسته‌بندی نوع داروی مناسب برای بیماران بر اساس ویژگی‌های پزشکی پیاده‌سازی شده است.

## ساختار پوشه
* **`j26.ipynb`**: نوت‌بوک جیومتریک حاوی مراحل بارگذاری داده‌ها، کدگذاری متغیرهای متنی (Label Encoding)، آموزش مدل با معیار انتروپی (Entropy) و ارزیابی دقت.
* **`drug200.csv`**: دیتاست حاوی اطلاعات بیماران (سن، جنسیت، فشار خون، کلسترول، نسبت سدیم به پتاسیم و داروی تجویز شده).

## ابزارها و کتابخانه‌ها
* **Python**
* **Pandas & NumPy**
* **Scikit-Learn** (برای مدل Decision Tree و پیش‌پردازش LabelEncoder)
* **Matplotlib**
