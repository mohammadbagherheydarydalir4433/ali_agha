# طبقه‌بندی داده‌های غیرخطی (Moons Dataset Classification) با ماشین بردار پشتیبان (SVM)

این پروژه شامل پیاده‌سازی و ارزیابی یک مدل دسته‌بندی با استفاده از الگوریتم **ماشین بردار پشتیبان (Support Vector Machine - SVM)** با هسته شعاعی یا `RBF Kernel` است تا بتواند داده‌های با توزیع غیرخطی و پیچیده (مانند الگوهای هلالی شکل) را بهه‌طور دقیق تفکیک و دسته‌بندی کند.

## ساختار پوشه
* **`j25.ipynb`** (یا نوت‌بوک پروژه): نوت‌بوک جیومتریک حاوی مراحل بارگذاری داده‌ها، جداسازی ویژگی‌ها و برچسب‌ها (`label`)، تقسیم‌بندی داده‌ها (`train_test_split`)، مقیاس‌دهی با `StandardScaler`، پیاده‌سازی مدل SVM غیرخطی و ارزیابی کیفیت خروجی.
* **`classification_moons.csv`**: دیتاست شامل مختصات نقاط دو بعدی (`x1`, `x2`) و برچسب کلاس مربوطه (`label`).

## مراحل و قابلیت‌های پروژه
1. **بارگذاری و بررسی داده‌ها:** خواندن فایل CSV و بررسی ساختار اولیه دیتاست[cite: 17].
2. **پیش‌پردازش و استانداردسازی:** مقیاس‌دهی متغیرها با استفاده از `StandardScaler` جهت بهبود عملکرد محاسباتی الگوریتم‌های مبتنی بر فاصله.
3. **تقسیم‌بندی داده‌ها:** تفکیک مجموعه داده به داده‌های آموزش و آزمون (80 درصد آموزش و 20 درصد آزمون).
4. **آموزش مدل SVM:** فیت کردن مدل `SVC` با استفاده از هسته غیرخطی `rbf` برای انطباق با ساختار هلالی داده‌ها.
5. **ارزیابی و گزارش‌گیری:** ارزیابی عملکرد مدل با استفاده از معیارهای استاندارد:
   * دقت کلی مدل (`Accuracy`)
   * ماتریس درهم‌ریختگی (`Confusion Matrix`)
   * گزارش کامل طبقه‌بندی شامل `Precision`، `Recall` و `F1-Score`.
