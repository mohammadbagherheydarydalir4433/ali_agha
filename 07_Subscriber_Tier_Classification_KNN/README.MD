# پیش‌بینی عملکرد تحصیلی دانش‌آموزان (Student Performance Prediction) با رگرسیون لجستیک

این پروژه یک مدل یادگیری ماشین با استفاده از الگوریتم دسته‌بندی **رگرسیون لجستیک (Logistic Regression)** است که برای پیش‌بینی وضعیت قبولی یا عدم قبولی دانش‌آموزان (`passed`) بر اساس ویژگی‌های تحصیلی پیاده‌سازی شده است.

## ساختار پوشه
* **`j.logistic.ipynb`**: نوت‌بوک جیومتریک حاوی مراحل بارگذاری داده‌ها، پیش‌پردازش، استانداردسازی ویژگی‌ها با `StandardScaler`، تقسیم‌بندی داده‌ها، آموزش مدل و ارزیابی عملکرد.
* **`student_performance1000.csv`**: دیتاست حاوی اطلاعات و امتیازات تحصیلی دانش‌آموزان (مانند ساعات مطالعه، نمرات قبلی، ساعات خواب، نمره نهایی و وضعیت قبولی).

## مراحل اصلی پیاده‌سازی
1. **بارگذاری و بررسی داده‌ها:** خواندن فایل CSV و بررسی ساختار اولیه دیتاست و ویژگی‌ها.
2. **انتخاب ویژگی‌ها (Features):** انتخاب متغیرهای موثر نظیر ساعات مطالعه (`hours_studied`)، نمره قبلی (`previous_score`)، ساعات خواب و نمره نهایی.
3. **استانداردسازی داده‌ها:** مقیاس‌دهی ویژگی‌ها با استفاده از `StandardScaler` برای بهینه‌سازی عملکرد مدل.
4. **تقسیم‌بندی داده‌ها:** تفکیک مجموعه داده به داده‌های آموزش (Train) و آزمون (Test).
5. **آموزش مدل:** پیاده‌سازی الگوریتم رگرسیون لجستیک با کتابخانه Scikit-Learn (با استفاده از کتابخانه `liblinear`).
6. **ارزیابی مدل:** بررسی کارایی مدل با استفاده از معیارهای استاندارد:
   * ماتریس درهم‌ریختگی (Confusion Matrix)
   * گزارش کامل طبقه‌بندی (Classification Report - Precision, Recall, F1-Score)
   * شاخص جاکارد (Jaccard Score)

## ابزارها و کتابخانه‌های مورد استفاده
* **Python**
* **Pandas & NumPy** (مدیریت و پردازش داده‌ها)
* **Scikit-Learn** (پیاده‌سازی مدل‌های یادگیری ماشین، استانداردسازی و ارزیابی)
* **Matplotlib** (مصورسازی داده‌ها)
