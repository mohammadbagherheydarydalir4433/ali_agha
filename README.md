# پروژه پیش‌بینی دسته‌بندی مشتریان مخابراتی با الگوریتم KNN (Customer Segmentation & K-Nearest Neighbors)

این مخزن شامل پروژه‌ها، دیتاست‌ها و کدهای یادگیری ماشین و تحلیل داده با زبان پایتون است. این بخش به پیاده‌سازی مدل دسته‌بندی **KNN** برای پیش‌بینی و طبقه‌بندی مشتریان (`custcat`) بر اساس ویژگی‌های جمعیتی و اقتصادی می‌پردازد.

## 📁 فایل‌های موجود در مخزن
- **`j20.ipynb`** (نوت‌بوک فعلی): بارگذاری داده‌ها، پیش‌پردازش، استانداردسازی، تقسیم داده‌های آموزشی و تست، آموزش مدل KNN و ارزیابی دقت مدل برای مقادیر مختلف K[cite: 17].
- سایر نوت‌بوک‌ها و اسکریپت‌های مرتبط با تحلیل داده.

## 🚀 ابزارها و کتابخانه‌های استفاده‌شده
- **Python**[cite: 17]
- **Pandas & NumPy** (بارگذاری دیتاست، مدیریت داده‌ها و محاسبات آرایه‌ای)[cite: 17]
- **Scikit-Learn** 
  - `preprocessing.StandardScaler` (برای نرمال‌سازی و استانداردسازی ویژگی‌ها)[cite: 17]
  - `model_selection.train_test_split` (تقسیم داده‌ها به بخش‌های Train و Test)[cite: 17]
  - `neighbors.KNeighborsClassifier` (پیاده‌سازی الگوریتم KNN)[cite: 17]
  - `metrics` (ارزیابی دقت مدل با `accuracy_score`)[cite: 17]
- **Matplotlib** (مصورسازی داده‌ها و رسم نمودارهای دقت مدل)[cite: 17]

## 📊 مراحل اجرای پروژه
1. **بارگذاری دیتاست:** خواندن فایل داده‌های مشتریان مخابراتی (`teleCust1000t.csv`)[cite: 17].
2. **پیش‌پردازش و استانداردسازی:** تبدیل مقادیر ویژگی‌ها با استفاده از `StandardScaler` جهت مقیاس‌دهی یکنواخت[cite: 17].
3. **تقسیم داده‌ها:** جداسازی دیتاست به مجموعه‌های آموزش (Train) و تست (Test)[cite: 17].
4. **آموزش مدل:** پیاده‌سازی دسته‌بند KNN با مقدار اولیه مشخص برای تعداد همسایگان ($K=4$) و آموزش روی داده‌ها[cite: 17].
5. **ارزیابی و بهینه‌سازی:** بررسی میزان دقت (Accuracy) روی مجموعه داده‌های تست و ارزیابی عملکرد مدل برای مقادیر مختلف K همراه با ترسیم نمودار خطای استاندارد[cite: 17].
