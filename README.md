# پروژه پیش‌بینی قیمت مسکن و املاک با رگرسیون خطی (Real Estate Price Prediction)

این مخزن شامل پروژه‌ها و کدهای یادگیری ماشین و تحلیل داده با استفاده از زبان پایتون است. این بخش به پیاده‌سازی مدل **رگرسیون خطی (Linear Regression)** جهت پیش‌بینی قیمت املاک (`toman`) بر اساس متراژ (`metrazh`) اختصاص دارد.

## 📁 فایل‌های موجود در مخزن
- **`j14.ipynb`** (نوت‌بوک فعلی): پیاده‌سازی رگرسیون خطی ساده روی دیتاست املاک (`real_estate_dataset_1000.csv`)[cite: 11].
- سایر پروژه‌ها و نوت‌بوک‌های یادگیری ماشین.

## 🚀 ابزارها و کتابخانه‌های استفاده‌شده
- **Python**
- **Pandas & NumPy** (بارگذاری، پاک‌سازی و پردازش داده‌ها)[cite: 11]
- **Scikit-Learn** (برای مدل‌سازی رگرسیون خطی، تفکیک داده‌ها و محاسبات ارزیابی خطا)[cite: 11]
- **Matplotlib / Pylab** (مصورسازی داده‌ها، رسم نمودارهای پراکندگی و خط رگرسیون)[cite: 11]

## 📊 مراحل اجرای پروژه
1. **بارگذاری دیتاست:** خواندن فایل اطلاعات املاک (`real_estate_dataset_1000.csv`) و نمایش نمونه‌ای از داده‌ها[cite: 11].
2. **بررسی آماری:** استفاده از دستور `describe()` برای دریافت آمار توصیفی داده‌ها[cite: 11].
3. **مصورسازی داده‌ها:** رسم نمودارهای پراکندگی (Scatter Plot) برای بررسی رابطه بین متغیرهای مختلف (مانند متراژ، سن بنا، تعداد اتاق و آدرس) با قیمت ملک (`toman`)[cite: 11].
4. **جداسازی داده‌های آموزش و تست:** تقسیم‌بندی داده‌ها به دو بخش Train و Test برای ارزیابی مدل[cite: 11].
5. **آموزش مدل:** ساخت شیء رگرسیون خطی و فیت کردن آن روی داده‌های آموزشی بر اساس ویژگی متراژ[cite: 11].
6. **ارزیابی مدل:** محاسبه معیارهای خطای میانگین مطلق (MAE)، میانگین مربعات خطا (MSE) و ضریب تعیین ($R^2$-score)[cite: 11].
