# پروژه تحلیل و بررسی قیمت کامودیتی‌ها (Commodities Prices Analysis)

این مخزن شامل پروژه‌ها، دیتاست‌ها و کدهای تحلیل داده با زبان پایتون است. این بخش به بارگذاری، توصیف آماری و بررسی داده‌های بازار جهانی فلزات گرانبها و مواد معدنی (`commodities_prices_1000.csv`) می‌پردازد.

## 📁 فایل‌های موجود در مخزن
- **`J17.ipynb`** (نوت‌بوک فعلی): بارگذاری و تحلیل توصیفی قیمت اقلامی مانند طلا، نقره، مس، سنگ آهن، پالادیوم، برنز و الماس[cite: 13].
- سایر اسکریپت‌ها و نوت‌بوک‌های مرتبط با تحلیل داده و یادگیری ماشین.

## 🚀 ابزارها و کتابخانه‌های استفاده‌شده
- **Python**
- **Pandas & NumPy** (بارگذاری دیتاست، مدیریت داده‌ها و محاسبات آماری)[cite: 13]
- **Matplotlib / Pylab** (مصورسازی داده‌ها و ترسیم نمودارهای تحلیلی)[cite: 13]

## 📊 مراحل اجرای پروژه
1. **بارگذاری دیتاست:** خواندن فایل داده‌های قیمت کامودیتی‌ها (`commodities_prices_1000.csv`) با استفاده از کتابخانه پانداز[cite: 13].
2. **مشاهده اولیه داده‌ها:** استفاده از متد `head()` برای نمایش سطرهای اول دیتاست[cite: 13].
3. **توصیف و آمار داده‌ها:** استفاده از متد `describe()` جهت بررسی میانگین، انحراف معیار، مقادیر حداقل و حداکثر برای هر کامودیتی[cite: 13].
4. **تحلیل ستون‌ها:** بررسی روند قیمتی طلا (`Gold_USD_Per_Oz`)، نقره (`Silver_USD_Per_Oz`)، مس (`Copper_USD_Per_Ton`)، سنگ آهن، پالادیوم، برنز و الماس[cite: 13].
