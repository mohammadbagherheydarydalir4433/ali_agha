# پروژه پیش‌بینی انتشار CO2 خودروها با رگرسیون چندجمله‌ای (Polynomial Regression & Fuel Consumption)

این مخزن شامل پروژه‌ها، دیتاست‌ها و کدهای یادگیری ماشین و تحلیل داده با زبان پایتون است. این بخش به پیاده‌سازی و ارزیابی مدل **رگرسیون چندجمله‌ای (Polynomial Regression)** برای پیش‌بینی میزان انتشار گاز CO2 بر اساس ویژگی‌های خودرو مانند حجم موتور (`ENGINESIZE`) می‌پردازد.

## 📁 فایل‌های موجود در مخزن
- **`j18.ipynb`** (نوت‌بوک فعلی): بارگذاری دیتاست مصرف سوخت، تبدیل ویژگی‌ها به فرم چندجمله‌ای، آموزش مدل و رسم نمودار خط رگرسیون[cite: 14, 15].
- سایر فایل‌ها و نوت‌بوک‌های مرتبط با تحلیل داده.

## 🚀 ابزارها و کتابخانه‌های استفاده‌شده
- **Python**
- **Pandas & NumPy** (بارگذاری دیتاست، مدیریت داده‌ها و محاسبات آرایه‌ای)[cite: 14, 15]
- **Scikit-Learn** (برای مدل‌سازی رگرسیون خطی، ایجاد ویژگی‌های چندجمله‌ای با `PolynomialFeatures` و ارزیابی خطا با مقدارهایی چون MAE، MSE و $R^2$-score)[cite: 14, 15]
- **Matplotlib / Pylab** (مصورسازی داده‌ها و ترسیم منحنی رگرسیون)[cite: 14, 15]

## 📊 مراحل اجرای پروژه
1. **بارگذاری دیتاست:** خواندن فایل داده‌های مصرف سوخت خودروها (`FuelConsumption.csv`)[cite: 14, 15].
2. **بررسی اولیه و فیلتر کردن ستون‌ها:** استخراج ویژگی‌های کلیدی مثل حجم موتور، تعداد سیلندر و میزان انتشار گاز CO2[cite: 14, 15].
3. **جداسازی مجموعه‌های آموزش و تست:** تقسیم داده‌ها به صورت تصادفی به دو بخش Train و Test[cite: 14, 15].
4. **تبدیل چندجمله‌ای (Polynomial Features):** اعمال تبدیل درجه ۲ روی داده‌های ورودی برای پوشش روابط غیرخطی[cite: 14, 15].
5. **آموزش مدل:** فیت کردن مدل رگرسیون خطی روی داده‌های تبدیل‌شده و استخراج ضرایب و عرض از مبدأ[cite: 14, 15].
6. **ارزیابی نهایی:** محاسبه معیارهای خطا از جمله خطای میانگین مطلق (MAE)، میانگین مربعات خطا (MSE) و ضریب تعیین ($R^2$-score)[cite: 14, 15].
