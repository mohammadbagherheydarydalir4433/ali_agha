# پروژه تحلیل و پیش‌بینی قیمت کامودیتی‌ها و فلزات گرانبها (Commodities Prices Prediction)

این مخزن شامل پروژه‌ها، دیتاست‌ها و کدهای تحلیل داده و یادگیری ماشین با زبان پایتون است. این بخش به بارگذاری، تحلیل توصیفی و بررسی قیمت کامودیتی‌های جهانی (`commodities_prices_1000.csv`) اختصاص دارد.

## 📁 فایل‌های موجود در مخزن
- **`J17.ipynb`** (نوت‌بوک فعلی): بارگذاری، پاک‌سازی و تحلیل توصیفی قیمت اقلامی چون طلا، نقره، مس، سنگ آهن، پالادیوم، برنز و الماس[cite: 13].
- سایر اسکریپت‌ها و نوت‌بوک‌های مرتبط با تحلیل داده و مدل‌سازی.

## 🚀 ابزارها و کتابخانه‌های استفاده‌شده
- **Python**
- **Pandas & NumPy** (بارگذاری دیتاست، مدیریت داده‌ها و محاسبات آماری)[cite: 13]
- **Matplotlib / Pylab** (مصورسازی داده‌ها و ترسیم نمودارهای روند بازار)[cite: 13]

## 📊 مراحل اجرای پروژه
1. **بارگذاری دیتاست:** خواندن فایل داده‌های قیمت کامودیتی‌ها (`commodities_prices_1000.csv`) با استفاده از کتابخانه پانداز[cite: 13].
2. **مشاهده اولیه داده‌ها:** استفاده از متد `head()` برای نمایش سطرهای اول جدول[cite: 13].
3. **توصیف و آمار داده‌ها:** استفاده از متد `describe()` جهت بررسی میانگین، انحراف معیار، مقادیر حداقل و حداکثر برای هر کامودیتی[cite: 13].
4. **تحلیل ستون‌ها:** بررسی روند قیمتی طلا (`Gold_USD_Per_Oz`)، نقره (`Silver_USD_Per_Oz`)، مس (`Copper_USD_Per_Ton`)، سنگ آهن، پالادیوم، برنز و الماس[cite: 13].
