# پروژه پیش‌بینی عملکرد تحصیلی دانشجویان (Student Performance Prediction)

این مخزن شامل کدهای مربوط به تحلیل داده‌ها و پیاده‌سازی مدل یادگیری ماشین با استفاده از الگوریتم **رگرسیون لجستیک (Logistic Regression)** برای پیش‌بینی موفقیت یا عدم موفقیت تحصیلی دانشجویان است.

## 📁 فایل‌های موجود در مخزن
- **`j.23.ipynb`**: پروژه قبلی (پیش‌بینی ریزش مشتری).
- **مایل جدید / نوت‌بوک فعلی**: شامل تحلیل دیتاست عملکرد دانشجویان (`student_performance1000.csv`)[cite: 8].

## 🚀 ابزارها و کتابخانه‌های استفاده‌شده
- **Python**
- **Pandas & NumPy** (مدیریت و پردازش داده‌ها)[cite: 8]
- **Scikit-Learn** (پیش‌پردازش داده‌ها، تقسیم‌بندی، آموزش مدل و ارزیابی)[cite: 8]
- **Matplotlib / Pylab** (مصورسازی داده‌ها)[cite: 8]

## 📊 مراحل اجرای پروژه
1. **بارگذاری دیتاست:** خواندن فایل داده‌های دانشجویان شامل ساعات مطالعه، نمرات قبلی، ساعات خواب و نمره نهایی[cite: 8].
2. **انتخاب ویژگی‌ها (Features):** انتخاب متغیرهای کلیدی مانند `hours_studied`، `previous_score`، `sleep_hours` و `final_score`[cite: 8].
3. **تعیین متغیر هدف (Target):** استفاده از ستون `passed` (وضعیت قبولی) به عنوان خروجی مدل[cite: 8].
4. **استانداردسازی و تفکیک داده‌ها:** مقیاس‌دهی داده‌ها با `StandardScaler` و تقسیم به بخش‌های آموزش (Train) و تست (Test)[cite: 8].
5. **آموزش مدل:** ساخت و فیت کردن مدل رگرسیون لجستیک (`LogisticRegression`)[cite: 8].
6. **ارزیابی مدل:** محاسبه ماتریس درهم‌ریختگی (Confusion Matrix)، گزارش دسته‌بندی (Classification Report) و شاخص جاکارد (Jaccard Score)[cite: 8].
