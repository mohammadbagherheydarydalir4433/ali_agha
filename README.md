# پروژه رگرسیون خطی پیش‌بینی انتشار CO2 خودروها (Linear Regression CO2 Emissions)

این مخزن شامل پروژه‌ها و کدهای یادگیری ماشین و تحلیل داده با استفاده از زبان پایتون است. این بخش به پیاده‌سازی مدل **رگرسیون خطی (Linear Regression)** جهت پیش‌بینی میزان انتشار گاز دی‌اکسید کربن (`CO2EMISSIONS`) بر اساس اندازه موتور (`ENGINESIZE`) خودروها اختصاص دارد.

## 📁 فایل‌های موجود در مخزن
- **`j13.ipynb`** (یا نوت‌بوک فعلی): پیاده‌سازی رگرسیون خطی ساده روی دیتاست مصرف سوخت (`FuelConsumption.csv`)[cite: 10].
- سایر نوت‌بوک‌های تمرینی تحلیل داده و یادگیری ماشین.

## 🚀 ابزارها و کتابخانه‌های استفاده‌شده
- **Python**
- **Pandas & NumPy** (بارگذاری، پاک‌سازی و پردازش داده‌ها)[cite: 10]
- **Scikit-Learn** (برای مدل‌سازی رگرسیون خطی، تفکیک داده‌ها و محاسبات ارزیابی)[cite: 10]
- **Matplotlib / Pylab** (مصورسازی داده‌ها و ترسیم خط رگرسیون)[cite: 10]

## 📊 مراحل اجرای پروژه
1. **بارگذاری دیتاست:** خواندن فایل اطلاعات مصرف سوخت (`FuelConsumption.csv`)[cite: 10].
2. **بررسی آماری و توصیف داده‌ها:** استفاده از دستورات `head()` و `describe()` برای شناخت ویژگی‌ها[cite: 10].
3. **مصورسازی داده‌ها:** رسم نمودارهای پراکندگی (Scatter Plot) جهت بررسی همبستگی متغیرها[cite: 10].
4. **جداسازی داده‌های آموزش و تست:** تقسیم‌بندی داده‌ها با استفاده از توابع تصادفی (`np.random.rand`) برای ارزیابی عملکرد مدل[cite: 10].
5. **آموزش مدل:** ساخت شیء رگرسیون خطی و فیت کردن آن روی داده‌های آموزشی (`train`)[cite: 10].
6. **ارزیابی مدل:** محاسبه معیارهای خطای میانگین مطلق (MAE)، میانگین مربعات خطا (MSE) و ضریب تعیین ($R^2$-score)[cite: 10].
