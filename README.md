# پروژه پیش‌بینی میزان انتشار CO2 خودروها با رگرسیون خطی (CO2 Emissions Prediction)

این مخزن شامل کدهای تحلیل داده و پیاده‌سازی یک مدل یادگیری ماشین با استفاده از الگوریتم **رگرسیون خطی (Linear Regression)** در زبان پایتون است تا میزان انتشار گاز کربن دی‌اکسید خودروها را بر اساس مشخصات موتور پیش‌بینی کند.

## 📁 فایل‌های موجود در مخزن
- **`j.23.ipynb`**: پروژه اول (پیش‌بینی ریزش مشتری با رگرسیون لجستیک).
- **`j.decision tree.ipynb`**: پروژه دوم (درخت تصمیم).
- **`j.logistic.ipynb`**: پروژه سوم (رگرسیون لجستیک عملکرد دانشجویان).
- **فایل فعلی**: پیاده‌سازی رگرسیون خطی ساده روی دیتاست مصرف سوخت (`FuelConsumption.csv`)[cite: 9].

## 🚀 ابزارها و کتابخانه‌های استفاده‌شده
- **Python**
- **Pandas & NumPy** (مدیریت، پاک‌سازی و پردازش داده‌ها)[cite: 9]
- **Scikit-Learn** (برای مدل‌سازی رگرسیون خطی، تفکیک داده‌ها و ارزیابی خطا)[cite: 9]
- **Matplotlib / Pylab** (مصورسازی و رسم نمودارهای پراکندگی و خط رگرسیون)[cite: 9]

## 📊 مراحل اجرای پروژه
1. **بارگذاری دیتاست:** خواندن فایل داده‌های مصرف سوخت خودروها (`FuelConsumption.csv`) و بررسی ویژگی‌های آن[cite: 9].
2. **توصیف و تحلیل اولیه:** استفاده از متد `describe` برای شناخت آماری داده‌ها[cite: 9].
3. **مصورسازی داده‌ها:** رسم نمودار پراکندگی (Scatter Plot) برای بررسی رابطه بین حجم موتور (`ENGINESIZE`)، تعداد سیلندر و مصرف سوخت با میزان انتشار `CO2EMISSIONS`[cite: 9].
4. **جداسازی داده‌های آموزش و تست:** تقسیم‌بندی داده‌ها به دو بخش Train و Test برای ارزیابی دقیق مدل[cite: 9].
5. **آموزش مدل رگرسیون خطی:** فیت کردن مدل روی داده‌های آموزشی و استخراج ضریب (Coefficient) و عرض از مبدأ (Intercept)[cite: 9].
6. **ارزیابی مدل:** محاسبه خطای میانگین مطلق (MAE)، میانگین مربعات خطا (MSE) و ضریب تعیین ($R^2$-score)[cite: 9].
