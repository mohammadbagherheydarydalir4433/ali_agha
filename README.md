# پروژه پیش‌بینی انتشار CO2 خودروها بر اساس مصرف سوخت ترکیبی (Fuel Consumption & CO2 Prediction)

این مخزن شامل پروژه‌ها، دیتاست‌ها و کدهای یادگیری ماشین و تحلیل داده با زبان پایتون است. این بخش به پیاده‌سازی و ارزیابی مدل **رگرسیون خطی (Linear Regression)** برای پیش‌بینی میزان انتشار گاز CO2 (`CO2EMISSIONS`) بر اساس مصرف سوخت ترکیبی (`FUELCONSUMPTION_COMB`) می‌پردازد.

## 📁 فایل‌های موجود در مخزن
- **`j.ipynb`** (نوت‌بوک فعلی): پیاده‌سازی مدل رگرسیون خطی روی دیتاست استاندارد مصرف سوخت (`FuelConsumption.csv`)[cite: 12].
- سایر اسکریپت‌ها و نوت‌بوک‌های تمرینی تحلیل داده.

## 🚀 ابزارها و کتابخانه‌های استفاده‌شده
- **Python**
- **Pandas & NumPy** (بارگذاری، استخراج ستون‌ها و محاسبات آرایه‌ای)[cite: 12]
- **Scikit-Learn** (برای مدل‌سازی رگرسیون خطی، پیش‌بینی و ارزیابی خطا با مقدارهایی چون MAE، MSE و $R^2$-score)[cite: 12]
- **Matplotlib / Pylab** (مصورسازی داده‌ها و ترسیم نمودارهای پراکندگی همراه با خط رگرسیون)[cite: 12]

## 📊 مراحل اجرای پروژه
1. **بارگذاری دیتاست:** خواندن فایل داده‌های مصرف سوخت خودروها (`FuelConsumption.csv`)[cite: 12].
2. **بررسی اولیه:** استفاده از `head()` و دستورات توصیفی برای شناخت ساختار جدول و ستون‌ها[cite: 12].
3. **مصورسازی:** رسم نمودار پراکندگی (Scatter Plot) جهت مشاهده روند همبستگی بین مصرف سوخت ترکیبی و انتشار گاز دی‌اکسید کربن[cite: 12].
4. **جداسازی مجموعه‌های آموزش و تست:** تقسیم تصادفی داده‌ها با استفاده از ماسک‌های بولی (`np.random.rand`) به دو بخش Train و Test[cite: 12].
5. **آموزش مدل رگرسیون خطی:** ساخت و فیت کردن مدل روی داده‌های آموزشی و محاسبه ضرایب (`coef_`) و عرض از مبدأ (`intercept_`)[cite: 12].
6. **ارزیابی نهایی:** تست مدل روی داده‌های تست و محاسبه معیارهای ارزیابی مانند خطای میانگین مطلق (MAE)، میانگین مربعات خطا (MSE) و ضریب تعیین ($R^2$-score)[cite: 12].
