# 02_Drug_Classification_Decision_Tree

این پروژه مربوط به دسته‌بندی و تجویز دارو بر اساس ویژگی‌های بیماران با استفاده از الگوریتم **درخت تصمیم (Decision Tree)** در کتابخانه Scikit-Learn پایتون است.

## اطلاعات پروژه
* **دیتاست:** `drug200.csv`[cite: 17]
* **مدل/الگوریتم:** Decision Tree Classifier (`criterion='entropy'`, `max_depth=4`)[cite: 13, 21]
* **هدف:** پیش‌بینی و طبقه‌بندی داروی مناسب (`drugA`, `drugB`, `drugC`, `drugX`, `drugY`) برای بیماران جدید بر اساس سن، جنسیت، فشار خون، کلسترول و نسبت سدیم به پتاسیم (`Na_to_K`)[cite: 13, 21].

## مراحل پیاده‌سازی در نوت‌بوک
1. بارگذاری کتابخانه‌ها (`numpy`, `pandas`, `DecisionTreeClassifier`)[cite: 13, 21]
2. خواندن و بررسی اولیه دیتاست (`drug200.csv`)[cite: 13, 21]
3. پیش‌پردازش و تبدیل متغیرهای متنی (Categorical) به مقادیر عددی با استفاده از `LabelEncoder` (`Sex`, `BP`, `Cholesterol`)[cite: 13, 21]
4. جداسازی داده‌ها به بخش‌های آموزش (Train) و تست (Test) با نسبت 80 به 20[cite: 13, 21]
5. ساخت، آموزش (`Fit`) و پیش‌بینی با مدل درخت تصمیم و محاسبه میزان دقت (`Accuracy`)[cite: 13, 21]
