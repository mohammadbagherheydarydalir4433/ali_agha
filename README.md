# پروژه پیش‌بینی نمره نهایی دانشجویان/دانش‌آموزان با رگرسیون خطی چندگانه (Student Performance Prediction)

این مخزن شامل پروژه‌ها، دیتاست‌ها و کدهای یادگیری ماشین و تحلیل داده با زبان پایتون است. این بخش به بارگذاری، تحلیل اکتشافی (EDA) و پیاده‌سازی مدل **رگرسیون خطی چندگانه** برای پیش‌بینی نمره نهایی (`final_score`) بر اساس ویژگی‌هایی مانند ساعات مطالعه، درصد حضور در کلاس، نمرات قبلی و ساعات خواب می‌پردازد.

## 📁 فایل‌های موجود در مخزن
- **`j21.ipynb`** (نوت‌بوک فعلی): بارگذاری دیتاست، رسم نمودارهای پراکندگی (Scatter Plots) برای ویژگی‌های مختلف، تقسیم داده‌ها به مجموعه‌های آموزش و تست، و پیاده‌سازی مدل رگرسیون چندگانه[cite: 19].
- سایر اسکریپت‌ها و نوت‌بوک‌های مرتبط با تحلیل داده و یادگیری ماشین.

## 🚀 ابزارها و کتابخانه‌های استفاده‌شده
- **Python**[cite: 19]
- **Pandas & NumPy** (بارگذاری دیتاست، استخراج ستون‌ها و محاسبات آرایه‌ای)[cite: 19]
- **Scikit-Learn** 
  - `linear_model.LinearRegression` (برای ساخت و آموزش مدل رگرسیون خطی)[cite: 19]
- **Matplotlib** (مصورسازی داده‌ها و ترسیم نمودارهای وابستگی ویژگی‌ها به نمره نهایی)[cite: 19]

## 📊 مراحل اجرای پروژه
1. **بارگذاری دیتاست:** خواندن فایل داده‌های عملکرد تحصیلی (`student_performance1000.csv`)[cite: 19].
2. **بررسی اولیه و فیلتر کردن ستون‌ها:** استخراج ویژگی‌های کلیدی نظیر ساعات مطالعه (`hours_studied`)، درصد حضور (`attendance_percent`)، نمره قبلی (`previous_score`) و ساعات خواب (`sleep_hours`)[cite: 19].
3. **مصورسازی داده‌ها:** رسم نمودارهای پراکندگی برای بررسی میزان همبستگی هر ویژگی با نمره نهایی (`final_score`)[cite: 19].
4. **جداسازی مجموعه‌های آموزش و تست:** تقسیم تصادفی داده‌ها به دو بخش Train و Test[cite: 19].
5. **آموزش مدل:** فیت کردن مدل رگرسیون خطی چندگانه روی ویژگی‌های منتخب و استخراج ضرایب (`Coefficients`) و عرض از مبدأ (`Intercept`)[cite: 19].
6. **ارزیابی نهایی:** محاسبه معیارهای ارزیابی مانند مجموع مربعات خطا (MSE) و ضریب تعیین (Variance Score / $R^2$)[cite: 19].
