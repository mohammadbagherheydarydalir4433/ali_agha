# ali_agha# پروژه پیش‌بینی ریزش مشتری (Customer Churn Prediction)

این پروژه یک مدل یادگیری ماشین با استفاده از الگوریتم **رگرسیون لجستیک (Logistic Regression)** پیاده‌سازی می‌کند تا بر اساس داده‌های مخابراتی یا خدماتی، احتمال ریزش (خروج) مشتریان را پیش‌بینی کند.

## 🚀 ابزارها و کتابخانه‌های استفاده‌شده
- **Python 3.12**
- **Pandas & NumPy** (برای مدیریت و تحلیل داده‌ها)
- **Scikit-Learn** (برای پیش‌پردازش، مدل‌سازی و ارزیابی)
- **Matplotlib / Pylab** (برای مصورسازی داده‌ها)

## 📊 مراحل اجرای پروژه
1. **بارگذاری کتابخانه‌ها و دیتاست:** خواندن فایل داده‌های مشتریان (`ChurnData.csv`)[cite: 5].
2. **انتخاب ویژگی‌ها (Features):** جداسازی ویژگی‌های مهم مانند مدت زمان اشتراک (`tenure`)، سن (`age`)، درآمد (`income`) و غیره به همراه متغیر هدف (`churn`)[cite: 5].
3. **استانداردسازی داده‌ها:** استفاده از `StandardScaler` برای مقیاس‌دهی ویژگی‌ها[cite: 5].
4. **تقسیم‌بندی داده‌ها:** جداسازی داده‌ها به دو بخش آموزش (Train - 80%) و تست (Test - 20%)[cite: 5].
5. **آموزش مدل:** ساخت و آموزش مدل رگرسیون لجستیک[cite: 5].
6. **ارزیابی مدل:** محاسبه ماتریس درهم‌ریختگی (Confusion Matrix)، گزارش دسته‌بندی (Classification Report) و شاخص جاکارد (Jaccard Index)[cite: 5].
