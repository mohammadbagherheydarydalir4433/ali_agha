# پروژه پیش‌بینی ریزش مشتری با یادگیری ماشین (Customer Churn Prediction)

این مخزن شامل پروژه‌های تحلیل داده و یادگیری ماشین برای پیش‌بینی احتمال ریزش (خروج) مشتریان بر اساس داده‌های مخابراتی است.

## 📁 فایل‌های پروژه
1. **`j.23.ipynb`**: پیاده‌سازی مدل با استفاده از الگوریتم **رگرسیون لجستیک (Logistic Regression)**.
2. **`j.decision tree.ipynb`**: پیاده‌سازی مدل با استفاده از الگوریتم **درخت تصمیم (Decision Tree)**.

## 🚀 ابزارها و کتابخانه‌های استفاده‌شده
- **Python**
- **Pandas & NumPy** (مدیریت و تحلیل داده‌ها)
- **Scikit-Learn** (پیاده‌سازی مدل‌های یادگیری ماشین، استانداردسازی و ارزیابی)
- **Matplotlib** (مصورسازی داده‌ها)

## 📊 مراحل انجام کار در مدل درخت تصمیم
1. بارگذاری و پیش‌پردازش دیتاست.
2. تفکیک ویژگی‌ها (Features) و متغیر هدف (Target).
3. تقسیم داده‌ها به بخش‌های آموزشی (Train) و آزمایشی (Test).
4. ساخت و آموزش مدل درخت تصمیم (`DecisionTreeClassifier`).
5. ارزیابی مدل و پیش‌بینی خروجی‌ها.
