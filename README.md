# Machine Learning Classification Projects 🤖📊

این ریپازیتوری شامل پروژه‌های تمرینی و کاربردی یادگیری ماشین (Machine Learning) با استفاده از زبان برنامه‌نویسی پایتون و کتابخانه قدرتمند Scikit-Learn است.

---

## 📁 ساختار پروژه‌ها

### ۱. دسته‌بندی گونه‌های گل زنبق (Iris Dataset Classification)
* **الگوریتم:** رگرسیون لجستیک (Logistic Regression)
* **فایل‌ها:** `j25_2.ipynb` و `classification_iris.csv`
* **توضیحات:** در این پروژه، گل‌های زنبق بر اساس ویژگی‌های فیزیکی (طول و عرض کاسبرگ و گلبرگ) به سه گونه مختلف دسته‌بندی شده‌اند. برای بهبود عملکرد مدل، داده‌ها استانداردسازی (`StandardScaler`) شده و مدل با دقت بسیار بالایی ارزیابی شده است.
* **دقت مدل (Accuracy):** ~۹۷٪

### ۲. دسته‌بندی داده‌های هلالی شکل (Two Moons Dataset Classification)
* **الگوریتم:** ماشین بردار پشتیبان با هسته غیرخطی (SVM - RBF Kernel)
* **فایل‌ها:** `j26.ipynb` و `classification_moons.csv`
* **توضیحات:** این دیتاست شامل نقاطی به شکل دو هلال ماه درهم‌تنیده است که تفکیک آن‌ها با خطوط مستقیم ممکن نیست. با استفاده از هسته RBF در الگوریتم SVM، مدل توانسته است مرزهای غیرخطی را به خوبی یاد بگیرد و دسته‌ها را تفکیک کند.
* **دقت مدل (Accuracy):** ۹۵٪
