# طبقه‌بندی گونه‌های گل زنبق (Iris Species Classification) با رگرسیون لجستیک

این پروژه شامل پیاده‌سازی و ارزیابی یک مدل دسته‌بندی چندکلاسه با استفاده از الگوریتم **رگرسیون لجستیک (Logistic Regression)** است تا گونه‌های مختلف گل زنبق (`species`) را بر اساس ویژگی‌های فیزیکی گلبرگ و کاسبرگ پیش‌بینی کند.

## ساختار پوشه
* **`j24.ipynb`** (یا نوت‌بوک پروژه): نوت‌بوک جیومتریک حاوی مراحل بارگذاری داده‌ها، جداسازی ویژگی‌ها و متغیر هدف، تقسیم‌بندی داده‌ها (`train_test_split`)، استانداردسازی مقادیر (`StandardScaler`)، آموزش مدل رگرسیون لجستیک و ارزیابی عملکرد.
* **`classification_iris.csv`**: دیتاست استاندارد زنبق شامل ویژگی‌های طول و عرض کاسبرگ و گلبرگ (`sepal length`, `sepal width`, `petal length`, `petal width`) و برچسب گونه‌های گل (`setosa`, `versicolor`, `virginica`).

## مراحل و قابلیت‌های پروژه
1. **بارگذاری و بازبینی داده‌ها:** خواندن فایل CSV و بررسی ساختار اولیه دیتاست[cite: 16].
2. **پیش‌پردازش و استانداردسازی:** مقیاس‌دهی ویژگی‌ها با استفاده از `StandardScaler` جهت بهبود همگرایی و عملکرد مدل لجستیک.
3. **تقسیم‌بندی داده‌ها:** تفکیک مجموعه داده به داده‌های آموزش و آزمون (80 درصد آموزش و 20 درصد آزمون).
4. **آموزش مدل:** فیت کردن مدل `LogisticRegression` بر روی داده‌های مقیاس‌شده‌ی آموزشی.
5. **ارزیابی و گزارش‌گیری:** محاسبه معیارهای ارزیابی کلیدی شامل:
   * دقت کلی مدل (`Accuracy Score`)
   * گزارش کامل طبقه‌بندی شامل معیارهای `Precision`، `Recall` و `F1-Score` برای هر گونه از گل‌ها.
