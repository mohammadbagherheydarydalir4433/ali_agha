# تحلیل مصرف سوخت و پیش‌بینی انتشار CO2 با رگرسیون خطی ساده

این پروژه یک مدل رگرسیون خطی ساده (Simple Linear Regression) است که رابطه بین حجم موتور خودرو (`ENGINESIZE`) و میزان انتشار گاز دی‌اکسید کربن (`CO2EMISSIONS`) را تحلیل و پیش‌بینی می‌کند.

## ساختار پوشه
* **`j.23.ipynb`** (یا نوت‌بوک پروژه): شامل مراحل بارگذاری داده‌ها، مصورسازی (Scatter Plot)، جداسازی داده‌های آموزش و آزمون، فیت کردن مدل و ارزیابی خطا.
* **`FuelConsumption.csv`**: دیتاست استاندارد مصرف سوخت خودروها.

## ابزارها و کتابخانه‌ها
* **Python**
* **Pandas & NumPy**
* **Scikit-Learn** (برای مدل LinearRegression و معیارهای ارزیابی مانند R2-score)
* **Matplotlib**
