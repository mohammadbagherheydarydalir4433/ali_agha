# پیش‌بینی ریزش مشتری (Customer Churn Prediction)

این پروژه با استفاده از الگوریتم **رگرسیون لجستیک (Logistic Regression)** برای پیش‌بینی احتمال ریزش مشتریان پیاده‌سازی شده است.

## محتویات پوشه
* **`j.23.ipynb`**: نوت‌بوک شامل مراحل پیش‌پردازش داده‌ها، استانداردسازی، آموزش مدل و ارزیابی با معیارهای مختلف (ماتریس درهم‌ریختگی، گزارش طبقه‌بندی و شاخص جاکارد).
* **`ChurnData.csv`**: دیتاست حاوی اطلاعات و ویژگی‌های مربوط به مشتریان.
