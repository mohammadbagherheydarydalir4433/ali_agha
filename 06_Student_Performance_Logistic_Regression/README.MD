# پیش‌بینی عملکرد تحصیلی دانش‌آموزان (Student Performance) با رگرسیون لجستیک

این پروژه یک مدل دسته‌بندی با استفاده از الگوریتم **رگرسیون لجستیک (Logistic Regression)** است که برای پیش‌بینی وضعیت قبولی یا عدم قبولی دانش‌آموزان (`passed`) بر اساس فاکتورهایی مانند ساعت مطالعه، نمرات قبلی، ساعت خواب و نمره نهایی توسعه یافته است.

## ساختار پوشه
* **`j17.ipynb`**: نوت‌بوک جیومتریک شامل مراحل پیش‌پردازش داده‌ها، تقسیم‌بندی Train/Test، آموزش مدل و ارزیابی با معیارهای تخصصی (ماتریس درهم‌ریختگی، گزارش طبقه‌بندی و شاخص جاکارد).
* **`student_performance1000.csv`**: دیتاست حاوی اطلاعات تحصیلی و عملکردی دانش‌آموزان.

## ابزارها و کتابخانه‌ها
* **Python**
* **Pandas & NumPy**
* **Scikit-Learn** (برای مدل LogisticRegression، استانداردسازی و معیارهای ارزیابی)
* **Matplotlib**
