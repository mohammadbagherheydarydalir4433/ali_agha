# طبقه‌بندی مشتریان (Customer Classification) با الگوریتم KNN

این پروژه شامل پیاده‌سازی و ارزیابی مدل یادگیری ماشین **K-Nearest Neighbors (KNN)** برای پیش‌بینی و دسته‌بندی دسته‌های مختلف مشتریان مخابراتی (`custcat`) بر اساس ویژگی‌های جمعیتی و اقتصادی است.

## ساختار پوشه
* **`j22.ipynb`** (یا نوت‌بوک پروژه): نوت‌بوک جیومتریک حاوی مراحل بارگذاری داده‌ها، پیش‌پردازش، استانداردسازی ویژگی‌ها (`StandardScaler`)، تقسیم‌بندی داده‌ها به مجموعه‌های آموزش و آزمون، آموزش مدل KNN، پیش‌بینی و ارزیابی دقت مدل در مقادیر مختلف K.
* **`teleCust1000t.csv`**: دیتاست مورد استفاده شامل اطلاعات مشتریان (مانند منطقه، سابقه، سن، وضعیت تأهل، درآمد، تحصیلات، شغل و ...) و دسته‌بندی مشتریان.

## مراحل و قابلیت‌های پروژه
1. **بارگذاری و بررسی داده‌ها:** خواندن فایل CSV و بررسی توزیع و مقادیر اولیه ویژگی‌ها.
2. **پیش‌پردازش و استانداردسازی:** مقیاس‌دهی متغیرها با استفاده از `StandardScaler` برای بهبود عملکرد فاصلهسنجی در الگوریتم KNN.
3. **آموزش و ارزیابی مدل:** تفکیک داده‌ها به داده‌های آموزش و تست و آموزش مدل با مقدار مشخصی از $K$ (مثلاً $K=4$).
4. **بهینه‌سازی پارامتر K:** بررسی و محاسبه دقت مدل (`Accuracy`) برای مقادیر مختلف $K$ (از ۱ تا ۱۰) به همراه محاسبه انحراف معیار خطاهای پیش‌بینی.

## ابزارها و کتابخانه‌های مورد استفاده
* **Python**
* **Pandas & NumPy** (برای پاکسازی و تحلیل داده‌ها)
* **Scikit-Learn** (برای مدل KNN، استانداردسازی، تقسیم‌بندی داده‌ها و معیارهای ارزیابی)
* **Matplotlib** (برای مصورسازی و رسم نمودار دقت مدل بر اساس مقادیر مختلف K)
