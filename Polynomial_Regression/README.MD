# پیش‌بینی میزان انتشار دی‌اکسید کربن خودروها (CO2 Emissions Prediction) با رگرسیون چندجمله‌ای

این پروژه شامل پیاده‌سازی و ارزیابی یک مدل یادگیری ماشین با استفاده از **رگرسیون چندجمله‌ای (Polynomial Regression)** با پایتون است تا رابطه غیرخطی بین اندازه موتور خودرو (`ENGINESIZE`) و میزان انتشار گاز دی‌اکسید کربن (`CO2EMISSIONS`) را مدل‌سازی و پیش‌بینی کند.

## ساختار پوشه
* **`j18.ipynb`** (یا نوت‌بوک پروژه): نوت‌بوک جیومتریک حاوی مراحل بارگذاری داده‌ها، رسم نمودارهای پراکندگی و خطوط رگرسیون غیرخطی، تبدیل ویژگی‌ها به فرمت چندجمله‌ای با `PolynomialFeatures`، آموزش مدل رگرسیون خطی روی داده‌های چندجمله‌ای و ارزیابی خطاها.
* **`FuelConsumption.csv`**: دیتاست استاندارد حاوی اطلاعات مصرف سوخت و آلایندگی خودروها.

## مراحل و قابلیت‌های پروژه
1. **بارگذاری و بررسی داده‌ها:** خواندن فایل CSV و استخراج ستون‌های کلیدی (مانند `ENGINESIZE` و `CO2EMISSIONS`).
2. **تبدیل ویژگی‌های چندجمله‌ای (Polynomial Features):** تبدیل داده‌های خطی به توابع درجه دوم (`degree=2`) برای انطباق بهتر با الگوهای خمیده و غیرخطی داده‌ها.
3. **آموزش مدل:** فیت کردن مدل `LinearRegression` روی داده‌های چندجمله‌ایِ تبدیل‌شده و استخراج ضرایب (`Coefficients`) و عرض از مبدأ (`Intercept`).
4. **مصورسازی مدل:** رسم نمودار پراکندگی داده‌های واقعی به‌همراه منحنی قرمز رنگ مدل رگرسیون چندجمله‌ای[cite: 18].
5. **ارزیابی مدل:** محاسبه معیارهای خطای پیش‌بینی شامل:
   * میانگین خطای مطلق (`Mean Absolute Error - MAE`)
   * میانگین مربعات خطا (`Residual Sum of Squares / MSE`)
   * ضریب تعیین (`R2-score`)
