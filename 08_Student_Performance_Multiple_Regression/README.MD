# پیش‌بینی نمره نهایی دانش‌آموزان (Student Final Score Prediction) با رگرسیون خطی

این پروژه شامل تحلیل اکتشافی داده‌ها (EDA) و پیاده‌سازی مدل **رگرسیون خطی چندگانه (Multiple Linear Regression)** با استفاده از پایتون است تا نمره نهایی دانش‌آموزان (`final_score`) بر اساس ویژگی‌های تأثیرگذاری همچون ساعات مطالعه، درصد حضور در کلاس، نمرات قبلی، ساعات خواب و فعالیت‌های فوق‌برنامه پیش‌بینی شود.

## ساختار پوشه
* **`j20.ipynb`** / **`j21.ipynb`**: نوت‌بوک‌های جیومتریک حاوی مراحل بارگذاری داده‌ها، رسم نمودارهای پراکندگی (Scatter Plots) جهت بررسی رابطه ویژگی‌ها با نمره نهایی، و آماده‌سازی داده‌ها.
* **`j22.ipynb`**: نوت‌بوک حاوی پیاده‌سازی مدل رگرسیون خطی، محاسبه ضرایب (Coefficients)، عرض از مبدأ (Intercept)، و ارزیابی مدل با معیارهایی نظیر مجموع مربعات خطا (Residual Sum of Squares) و ضریب تعیین (Variance Score / $R^2$).
* **`student_performance1000.csv`**: دیتاست جامع حاوی اطلاعات تحصیلی و نمرات ۱۰۰۰ دانش‌آموز.

## مراحل و قابلیت‌های پروژه
1. **بارگذاری و پاکسازی داده‌ها:** خواندن فایل CSV و تنظیم نام ستون‌ها.
2. **تحلیل اکتشافی داده‌ها (EDA):** مصورسازی رابطه بین ویژگی‌های مختلف (مانند `hours_studied`, `attendance_percent`, `previous_score`) و متغیر هدف (`final_score`) با استفاده از کتابخانه Matplotlib.
3. **آموزش مدل رگرسیون خطی چندگانه:** تفکیک داده‌ها به دو بخش آموزش (Train) و تست (Test) و فیت کردن مدل روی ویژگی‌های انتخابی.
4. **ارزیابی عملکرد مدل:** 
   * محاسبه ضرایب رگرسیون و عرض از مبدأ.
   * محاسبه مجموع مربعات باقیمانده (MSE / Residual sum of squares).
   * ارزیابی دقت مدل با استفاده از امتیاز واریانس (`Variance Score`).
